32 · Aplicação

Acessibilidade

WCAG AA é o mínimo. O iAdm é denso — então navegação por teclado, foco visível e contraste são inegociáveis.

Contraste AA
Texto 4.5:1, UI 3:1. Dourado só com texto escuro.
Foco visível
Ring dourado em todo elemento focável (:focus-visible).
Teclado
Tab em todos os fluxos; ⌘K abre a busca; Esc fecha overlays.
ARIA
Labels em ícones-only, modais (role=dialog), tabelas.
Movimento
prefers-reduced-motion reduz animações a 0.01ms.
Não só cor
Status sempre tem texto + ícone, nunca só a cor do badge.
33 · Aplicação

Do / Don't

As regras que mantêm o iAdm consistente com os outros apps do L4 OS via @l4/ui.

Faça
  • Use tokens (--gold-600, --success) — nunca hex solto
  • Dourado para ação; paleta categórica só em gráficos
  • Valores monetários em font-mono alinhados à direita
  • Skeleton para listas, spinner só em ações pontuais
  • Status sempre com texto + ícone, não só cor
  • Reaproveite componentes do @l4/ui
Não faça
  • Não use roxo/azul de gráfico em botões ou CTAs
  • Não crie Button/Card/Modal próprios — use @l4/ui
  • Não use spinner em listas longas (use skeleton)
  • Não misture fontes — só Inter + JetBrains Mono
  • Não use outline:none sem :focus-visible
  • Não exagere em sombras — densidade pede sutileza
